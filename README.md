# SamCore DevVault 🚀

A professional developer profile management platform built with Node.js, Express, MongoDB, EJS, and Tailwind CSS.

## ✨ Features

- User Registration & Login
- JWT Authentication
- Admin Dashboard
- User Profile Management
- Edit Profile System
- Audit Logs Tracking
- Soft Delete / Restore Users
- Project & Language Management
- Professional Light UI Design

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Tailwind CSS
- JWT
- bcrypt

## 📌 Main Modules

### User Side
- Register
- Login
- Profile View
- Edit Profile
- Project Management

### Admin Side
- View All Users
- Delete User
- Restore User
- Activity Logs
- Dashboard Stats
